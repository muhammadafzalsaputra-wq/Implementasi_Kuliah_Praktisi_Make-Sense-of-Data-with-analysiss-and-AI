# PT Maju Bersama — Business Performance Analytics (Tanpa Python)

Proyek dashboard edukasi menggunakan HTML, CSS, dan JavaScript. Seluruh data di dalam aplikasi dibuat secara simulasi.

## Cara menjalankan
1. Ekstrak folder proyek.
2. Buka folder di VS Code.
3. Klik kanan `index.html` lalu pilih **Open with Live Server** jika ekstensi Live Server tersedia; atau buka `index.html` langsung di browser.
4. Chart.js dimuat dari CDN sehingga koneksi internet diperlukan untuk grafik.

## Fitur
- Ringkasan KPI: penjualan, laba, piutang, arus kas.
- Tren bulanan dan perbandingan tahunan.
- Analisis Descriptive, Diagnostic, Predictive, Prescriptive.
- Pemeriksaan kualitas data: duplikat, nilai negatif, nilai kosong, variasi nama.
- Analisis faktur dan skenario skor risiko sederhana.
- Insight dan rekomendasi untuk membantu pembacaan data.

## Metodologi
Mengikuti alur pembelajaran: Data → Informasi → Insight → Keputusan. Analisis mencakup empat jenis analitik: descriptive, diagnostic, predictive, dan prescriptive. Data sintetis disusun agar beberapa indikator dapat menunjukkan tren yang berbeda, sehingga peserta dapat mempraktikkan interpretasi data.

## Keterbatasan
- Data simulasi bukan data aktual.
- Skor risiko merupakan aturan heuristik transparan, bukan model machine learning terlatih, dan bukan probabilitas gagal bayar.
- Insight yang tampil adalah interpretasi awal; hubungan sebab-akibat harus diuji dengan data tambahan.
- Grafik memakai Chart.js CDN; perlu internet saat membuka aplikasi.
